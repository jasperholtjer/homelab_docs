# Switch — Flex Mini 2.5G

UniFi Switch Flex Mini 2.5G (EU version), model USW-Flex-2.5G-5. Compact 5-port
2.5 GbE switch.

## Hardware

| Component | Spec                                            |
| --------- | ----------------------------------------------- |
| Model     | UniFi USW-Flex-2.5G-5 (EU version)              |
| Ports     | 5× 2.5 GbE                                       |

## Connected Devices

| Port | Device                                  |
| ---- | --------------------------------------- |
| 1    | [UNAS 2](unas.md) — network storage     |
| 4    | [NUC](nuc.md) — Proxmox host            |

The switch uplinks to the KPN Box 12 (gateway `192.168.2.254`). See the
[network overview](../network/overview.md) for the full topology.
